# Cirrus SF50 Vision Jet — facts used by the hwd3d model (M1, Phase 3)

Every value the builder (`build_sf50.py`, `sf50_geom.py`) uses is listed here with its source. **obs** = stated by the
source quoted; **inf** = inferred (read off a drawing, derived, or a modelling choice) with the method. Values read off
drawings are always **inf**, even when the drawing is the manufacturer's. Retrieved 2026-11-13. Reference documents
(PDFs, drawings, photos) were kept in a scratch directory only and are **not committed**.

**Fix round 3 (orchestrator decisions 2026-11-13 under the owner's delegation; the owner may overrule):** (a) the FAA DRS
public web viewer is the FAA's intended public interface for type certificate data sheets: values read there from TCDS
A00018CH / E3GL are **obs** with the TCDS citation (no longer "inf (DRS)"). (b) Digitised readings of the AFM figures
(outlines, stations, per-butt-line water lines, angles, raster scales) are **not committed**: they are local reference data
in the gitignored `refs/cache/local/models/afm_sf50_meas.json` (with a `src` note); this table keeps each fitted model
value and its basis. Dimension labels printed on the AFM figures (e.g. "11.1 ft (3.4 m)") are published values and stay
quoted.
